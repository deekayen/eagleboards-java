Running

java -jar EagleBoardScheduler.jar -p prereg_file -a adult_history_file
  1. Pre-registration auto-fill: start with the '-p file' option to load pre-registration (auto-fill) file
  2. Adult History auto-fill: start with the '-a file' option to load adult history (auto-fill) file
  3. Data Directory: use the '-d dir' option to specify the directory containing the data files, by default the data directory is a directory with the current date in the format of 'yyy-MM-dd'

Pages

  • / : Main Page
  • /youth_register : Youth Sign-in page
  • /adult_register : Adult Sign-in page
  • /scheduler : Scheduler page
  • /admin : Administration page
  • /configure : Settings/Colors configuration page

Room Setup

  1. Go to the 'Rooms' tab of the '/admin' page and add rooms.
  2. Rooms may be 'Final' or 'Project' Rooms.
  3. You must pre-allocate whether rooms are for Project reviews or Final boards.
  4. For 'Project' rooms where you may put multiple Project Boards in a single room, create Multiple Room entries like 200A and 200B with of type 'Project'.

Status Values

  1. Registered: The Youth has signed in and is ready to be seated
  2. Seated: The Adults are in the room with the application, references and project workbook. The Youth is still outside.
  3. InProgress: The Youth is in the Board room
  4. Completed: The Board is completed and a result has been entered.
  5. Postponed: The Youth arrived unprepared and was sent away without seeing a board. This is decided before a board is seated; once the board has met the Youth, its decision is the Result.

Process

  1. Sign-in: Youth/Adults sign in on sign-in screen
  2. Paperwork check: As Youth sign in, check their writeups and paperwork for the board. This is done off-screen — there is no longer a 'Verify' step in the User Interface. If the paperwork is not in order you may move them to 'Postponed' and they can reschedule for the next month.
  3. Seating: Once the paperwork is in order, you may seat a board. To do this:
    1. Select the youth in the Youth window of the scheduler page.
    2. The scheduler will 'auto-select' a board consisting of a registered 'Chair' and the appropriate number of 'Members' along with a room. It picks with the whole waiting line in mind: it keeps adults who can chair free for the boards still to come, and uses adults whose troop rules them out for youth still waiting. If there aren't enough adults to do that it still proposes the best board it can.
    3. If there are not enough adults or rooms available, the scheduler will post an error message
    4. You may override/change selections manually by selecting/un-selecting the check-box in the adults list.
    5. Once you have selected the proper number of adults and a room, you may 'Seat' the board
    6. Press the 'Seat Board' button above the Youth list.
    7. Confirm or change the Board Chair in the popup dialog.
    8. The youth's status will be moved to 'Seated'
  4. Starting: When the adults are ready to meet with the Youth, you can move the status to InProgress as follows:
    1. Select the Youth currently in the 'Seated' status
    2. The scheduler will attempt to locate the Scoutmaster or Life to Eagle coach for the Youth and print out a message showing where they are located. You may also get the location using the 'Locate' button.
    3. Go get the Youth and Scoutmaster(or Life to Eagle) coach who will introduce them.
    4. Once they have gone back change the status to 'InProgress' by pressing the 'Start Review' button.
  5. Completing: Once a board has finished and has the results you may complete the process as follows:
    1. Select the Youth in the Youth List
    2. The scheduler will attempt to locate the Adult Leaders and parents (with the same last name) of the Youth
    3. Go get the Youth, Scoutmaster and parents
    4. After the completion, move the status to 'completed' by pressing the 'Complete' button
    5. Enter the board's decision and any related comments: Approved; Adjourned (the board postpones its decision); or NotApproved.
  6. After completion, this will free up the adults and rooms associated with the board.
  7. Correcting a result: on the Admin page's Boards tab, change the Result. If the result was recorded against the wrong Youth, give the Youth who was actually reviewed the Status 'Completed', the Result, Chair and Members, and set the other Youth's Status back to 'Registered' with the Result, Chair and Members cleared. They can then be seated for their own board.

Board Timers

The scheduler supports board timers that will alert the user when a Board has not changed status in a pre-set amount of time then post a reminder every few minutes. This is applicable to the 'Seated' and 'InProgress' status values. You may use these to check on (move-along) boards that seem to be taking too long. These values may be set through the 'Settings' screen.

Administration Page

  1. The Admin page has lists for:
    • Boards: View the current status
    • Youth: You may see the currently registered youth and modify fields
    • Youth Scheduled: You may see the pre-registered youth
    • Adults: View/modify the list of adults who have signed-in
    • Adult History: View modify the list of adults from the history/auto-fill file.
    • Rooms: View/Add/Remove rooms available for boards.

Settings Page

  • Configure application parameters
  • Set the page refresh time (seconds)
  • Set the Board Timer Alert time (minutes)
  • Set the Board Timer reminder time (minutes)
  • Configure the Status colors.

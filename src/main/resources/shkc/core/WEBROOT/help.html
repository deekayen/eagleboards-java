Running

java -jar EagleBoardScheduler.jar -p prereg_file -a adult_history_file
  1. Pre-registration auto-fill: start with the '-p file' option to load pre-registration (auto-fill) file
  2. Adult History auto-fill: start with the '-a file' option to load adult history (auto-fill) file
  3. Data Directory: use the '-d dir' option to specify the directory containing the data files, by default the data directory is a directory with the current date in the format of 'yyy-MM-dd'

Pages

  • / : Main Page
  • /scout_register : Scout Sign-in page
  • /admin_register : Adult Sign-in page
  • /scheduler : Scheduler page
  • /admin : Administration page
  • /config: Settings/Colors configuration page

Room Setup

  1. Go to the 'Rooms' tab of the '/admin' page and add rooms.
  2. Rooms may be 'Final' or 'Project' Rooms.
  3. You must pre-allocate whether rooms are for Project reviews or Final boards.
  4. For 'Project' rooms where you may put multiple Project Boards in a single room, create Multiple Room entries like 200A and 200B with of type 'Project'.

Status Values

  1. Registered: The Scout has signed in
  2. Verified: The Scouts paperwork has been checked and is ready to seat the board
  3. Seated: The Adults have been seated for the review
  4. InProgress: The Scout is in the Board room
  5. Completed: The Board is completed and a result has been entered.
  6. Postponed: The Board ihas been postponed, probably due to a paperwork or preparation issue.

Process

  1. Sign-in: Scouts/Adults sign in on sign-in screen
  2. Verification: As Scouts sign in, verify their writeups and paperwork for the board. If all is well, 'Verify' them through the User Interface. If the paperwork is not in order you may move them to 'Postponed' and they can reschedule for the next month.
  3. Seating: Once verified, you may seat a board. To do this:
    1. Select the scout in the Scouts window of the scheduler page.
    2. The scheduler will 'auto-select' a board consisting of a registered 'Chair' and the appropriate number of 'Members' along with a room.
    3. If there are not enough adults or rooms available, the scheduler will post an error message
    4. You may override/change selections manually by selecting/un-selecting the check-box in the adults list.
    5. Once you have selected the proper number of adults and a room, you may 'Seat' the board
    6. Press the 'Seat' button above the Scouts list.
    7. Confirm or change the Board Chair in the popup dialog.
    8. The scouts status will be moved to 'Seated'
  4. Starting: When the adults are ready to meet with the Scout, you can move the status to InProgress as follows:
    1. Select the Scout currently in the 'Seated' status
    2. The scheduler will attempt to locate the Scoutmaster or Life to Eagle coach for the Scout and print out a message showing where they are located. You may also get the location using the 'Locate' button.
    3. Go get the Scout and Scoutmaster(or Life to Eagle) coach who will introduce them.
    4. Once they have gone back change the status to 'InProgress' by pressing the 'Start' button.
  5. Completing: Once a board has finished and has the results you may complete the process as follows:
    1. Select the Scout in the Scouts List
    2. The scheduler will attempt to locate the Adult Leaders and parents (with the same last name) of the Scout
    3. Go get the Scout, Scoutmaster and parents
    4. After the completion, move the status to 'completed' by pressing the 'Complete' button
    5. Enter the final board result and enter any related comments.
  6. After completion, this will free up the adults and rooms associated with the board.

Board Timers

The scheduler supports board timers that will alert the user when a Board has not changed status in a pre-set amount of time then post a reminder every few minutes. This is applicable to the 'Seated' and 'InProgress' status values. You may use these to check on (move-along) boards that seem to be taking too long. These values may be set through the 'Settings' screen.

Administration Page

  1. The Admin page has lists for:
    • Boards: View the current status
    • Scouts: You may see the currently registered scouts and modify fields
    • Preregistered Scouts: You may see the pre-registered scouts
    • Adults: View/modify the list of adults who have signed-in
    • Adult History: View modify the list of adults from the history/auto-fill file.
    • Rooms: View/Add/Remove rooms available for boards.

Settings Page

  • Configure application parameters
  • Set the page refresh time (seconds)
  • Set the Board Timer Alert time (minutes)
  • Set the Board Timer reminder time (minutes)
  • Configure the Status colors.
